# What is Small notes beat big notes
A short note gets read. A long note gets admired once and then avoided, because reading it means
starting a project.

# Why it matters
The point of a note is to be picked up again later, and a short one can be picked up in ten seconds
while the kettle boils.

# Where it showed up
Every notebook I stopped rereading had grown into a half finished essay on the first page.
